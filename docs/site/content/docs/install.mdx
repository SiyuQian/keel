title: Run Keel from source
description: Set up the current Keel development build on macOS, Windows, or Linux.
---

Keel is being developed from Orca. Use source builds for this project; Orca's
installers, Homebrew packages, and update channels are upstream distributions.
This documentation change does not configure Keel release artifacts or signing.

## Prerequisites

Install Node 24, pnpm, and the Bun version pinned in `config/.bun-version`.
Native builds may also require your platform's compiler toolchain; follow
`.github/CONTRIBUTING.md` in the repository.

## Run the desktop application

```sh
git clone https://github.com/SiyuQian/keel.git
cd keel
pnpm install
pnpm dev
```

For agent-launched apps and tests, set `ORCA_BACKGROUND_LAUNCH=1` to keep windows
hidden. The current application can still display the Orca name. The CLI is
`orca`, not `keel`; keep `ORCA_*` variables and existing configuration paths.

## Packaging and updates

Before cross-architecture packaging, run `pnpm install:release`. The current
packaging and updater configuration retains upstream identifiers. Review
`docs/UPSTREAM.md` and `docs/exec-plans/tech-debt-tracker.md` in the repository
before publishing or relying on automatic updates in an independent build.

Keel-specific download URLs, app-store listings, signing, and update channels
must be documented after they are configured and verified.

## Mobile and remote execution

[Mobile](/docs/mobile) has its own source setup in `mobile/README.md`.
For self-hosted execution, read [remote servers](/docs/remote-servers) and
[SSH](/docs/ssh). Upstream hosted infrastructure is not assumed to serve Keel.
